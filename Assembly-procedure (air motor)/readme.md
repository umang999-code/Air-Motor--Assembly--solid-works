# Air Motor Assembly Procedure

This section presents the step-by-step assembly procedure of the Air Motor developed in SolidWorks. The assembly is constructed systematically by positioning the base, structural components, shaft, rotating elements, and remaining mechanical components.

## Assembly Sequence

### Step 1 — Base Plate:
https://github.com/umang999-code/Air-Motor--Assembly--solid-works/blob/main/Assembly-procedure%20(air%20motor)/step%201.png

The assembly begins with the base plate, which acts as the foundation of the complete air motor.

- Insert the base plate into the assembly.
- Fix the base plate at the assembly origin.
- Use the base plate as the primary reference for subsequent components.

### Step 2 — Lower Components:
https://github.com/umang999-code/Air-Motor--Assembly--solid-works/blob/main/Assembly-procedure%20(air%20motor)/step%202.png

The lower support and mounting components are positioned on the base.

- Insert the required mounting components.
- Apply Coincident mates between contacting faces.
- Apply Concentric mates to align mounting holes.
- Verify proper seating on the base plate.

### Step 3 — Main Motor Housing:
https://github.com/umang999-code/Air-Motor--Assembly--solid-works/blob/main/Assembly-procedure%20(air%20motor)/step%203.png

The main motor housing is installed onto the lower support structure.

- Insert the motor housing.
- Align the mounting holes and reference surfaces.
- Apply Coincident and Concentric mates.
- Verify that the housing is securely positioned.

### Step 4 — Shaft / Rotating Assembly:
https://github.com/umang999-code/Air-Motor--Assembly--solid-works/blob/main/Assembly-procedure%20(air%20motor)/step%204.png


The main shaft is inserted through the motor housing.

- Insert the shaft into the housing.
- Apply a Concentric mate between the shaft and bearing/housing axis.
- Control axial position using Coincident or Distance mates.
- Ensure free rotational movement.

### Step 5 — Flywheel / Pulley:
https://github.com/umang999-code/Air-Motor--Assembly--solid-works/blob/main/Assembly-procedure%20(air%20motor)/step%205.png

The large flywheel is mounted on the shaft.

- Insert the flywheel.
- Apply a Concentric mate between the flywheel bore and shaft.
- Position the flywheel axially.
- Check radial and axial alignment.

### Step 6 — top plate Component
The top plate component is installed on the main motor structure.

- Align it with the housing and reference faces.
- Apply Coincident and Distance mates.
- Verify correct positioning.

### Step 7 — Front/Side Mechanism
The remaining mechanical components are installed to complete the working mechanism.

- Insert the required components.
- Align rotating elements with the shaft.
- Apply appropriate Concentric, Coincident and Distance mates.
- Check component clearances.

### Step 8 — Final Alignment
All remaining components and fasteners, bolts screw are installed.

- Complete the required mates.
- Check shaft and flywheel alignment.
- Verify that all structural components are properly constrained.
- Maintain rotational freedom for intended moving components.

### Step 9 — Final Assembly
The complete Air Motor assembly is finalized.

- Complete all remaining mates.
- Check the assembly from multiple views.
- Perform an interference/clearance check.
- Verify the movement of rotating components.
- Save the final SolidWorks assembly.

## Mate Types Used:

The primary SolidWorks mates used during assembly include:

- *Coincident Mate* — For joining contacting faces.
- *Concentric Mate* — For aligning cylindrical surfaces and shafts.
- *Distance Mate* — For controlling axial/component spacing.
- *Parallel Mate* — For maintaining component orientation.
- *Fix/Ground* — Used for the primary base/reference component.

## Assembly Verification:

Before finalizing the assembly:

- [x] Base properly fixed
- [x] Housing correctly aligned
- [x] Shaft concentric with housing
- [x] Flywheel aligned with shaft
- [x] Upper components positioned correctly
- [x] Remaining components installed
- [x] Required mates completed
- [x] Rotating components checked
- [x] Interference/clearance verified
- [x] Final assembly saved
