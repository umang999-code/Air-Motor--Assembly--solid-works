## Assembly File (.SLDASM)

Complete Air Motor assembly
All components assembled using appropriate SolidWorks mates
Ready for viewing, modification, and further CAD analysis

## Software Required:
SOLIDWORKS (recommended)
The assembly should be opened with all referenced .SLDPRT files available in the same project folder.


## How to Download:
Download the complete project folder/repository.
Keep the .SLDASM assembly and all .SLDPRT component files together.
Open the Air Motor .SLDASM file in SOLIDWORKS.
If SOLIDWORKS asks for missing components, browse to the folder containing the downloaded part files and locate them.
Once all references are found, the complete Air Motor assembly will load correctly.


## Important: 
Do not rename or move the individual .SLDPRT files after downloading, because the .SLDASM assembly contains references to the original component file names and locations.
